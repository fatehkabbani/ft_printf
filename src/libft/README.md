# Description

The goal of this project is to recode a library of standard C functions, called `libft`, that can be reused in other projects. The library includes functions for string manipulation, memory management, and other common operations.

# Instructions

1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Compile the library using the provided Makefile.
4. Use the library in your own C projects by including the header file and linking against the compiled library.
5. Refer to the documentation for a list of available functions and their usage.

# Details

The project is divided into three parts:

- **Part 1:** Reimplementing standard C library functions (libc).
- **Part 2:** Implementing additional functions that are not part of the standard C library but are commonly used in C programming.
- **Part 3:** Implementing linked list functions.
